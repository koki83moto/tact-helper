# TACT Helper

名古屋大学などで使われている学習支援システム **TACT**（東海国立大学機構）を便利にする Chrome 拡張機能です。

> **非公式ツールです。** 東海国立大学機構・名古屋大学・岐阜大学とは関係ありません。利用は自己責任でお願いします。

## 機能

### 課題の締切を Google カレンダーに自動登録
- 選択した講義について、未提出の課題・小テストの締切を Google カレンダーの専用カレンダー「TACT 課題」に登録します。
- 提出済みになった課題の予定は、自動で削除します。
- 締切が日本時間の 0:00 の課題は、わかりやすいように前日の 23:59 として登録します。
- 同期は、6 時間ごと・Chrome の起動時・TACT のページを開いたときに自動で行います。

### 授業資料（リソース）の一括ダウンロード
- 各講義のリソースを、フォルダ階層を保ったまま `保存先\講義名\...` に保存します。
- 手元にないファイルだけをダウンロードします。全角と半角、大文字と小文字の違いは同じ名前として扱います。
- 講義名の `[遠隔]` や `(2026年度秋1期/木3限)` などは取り除いて、フォルダ名にします。

## インストール

この拡張機能は Chrome ウェブストアでは公開していません。Google Calendar API を使うため、各自で OAuth クライアントを作成する必要があります。

### 1. ダウンロードして読み込む
1. このリポジトリを clone するか、ZIP をダウンロードして展開します。
2. Chrome で `chrome://extensions` を開き、右上の「デベロッパー モード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」で、展開したフォルダを選びます。
4. 表示される拡張機能の **ID**（32 文字の英字）を控えます。この ID は、フォルダの場所を変えない限り変わりません。

### 2. Google Calendar API の OAuth クライアントを作る
1. [Google Cloud Console](https://console.cloud.google.com/) で新しいプロジェクトを作成します。
2. 「API とサービス」→「ライブラリ」で **Google Calendar API** を有効にします。
3. 「OAuth 同意画面」（Google Auth Platform）を設定します。
   - ユーザーの種類: **外部**
   - 「対象」→「テストユーザー」に、自分の Google アカウントを追加します。
4. 「認証情報」→「認証情報を作成」→「OAuth クライアント ID」を作成します。
   - アプリケーションの種類: **Chrome 拡張機能**
   - アイテム ID: 手順 1 で控えた拡張機能の ID
5. 作成されたクライアント ID を、`manifest.json` の `oauth2.client_id` に貼り付けます。
6. `chrome://extensions` で拡張機能を再読み込みします。

> カレンダーには、**Chrome にログインしている Google アカウント**の予定として登録されます。
> 同意画面で「Google hasn't verified this app」と表示されますが、自分で作成したテスト中のアプリなので「Continue」で進んで構いません。

### 3. 使い方
1. TACT にログインします。
2. ツールバーの TACT Helper アイコンをクリックすると、管理画面が開きます。
3. 「Google に接続」を押して、カレンダーへのアクセスを許可します。
4. 「対象の講義」で、同期・ダウンロードの対象にする講義を選びます。初回は、TACT のお気に入りに入っている講義が選ばれています。
5. 「今すぐ同期」を押すと、カレンダーに締切が登録されます。
6. 「保存先フォルダを選択」で保存先を選びます。Google ドライブ for desktop のフォルダも選べます。
7. 「確認だけ」で足りないファイルを確認してから、「不足している資料をダウンロード」を押します。

## 注意点
- TACT のログインが切れていると同期できません。その場合はアイコンに「!」が表示されるので、TACT にログインしてください。
- 小テスト（テスト・クイズ）は、API から提出状況を取得できません。受験したら、管理画面で「完了」にチェックしてください。
- 「TACT 課題」カレンダーの予定は、この拡張機能が自動で追加・削除します。
- リソース内の Web リンクと HTML ページは保存しません。
- 中身だけが更新されたファイル（同じ名前のファイル）は、取り直しません。

## 仕組み
- TACT（Sakai）の REST API（`/direct/...`）を、ログイン中のセッションで呼び出しています。
- 資料の保存には File System Access API を使っています。
- 取得したデータを、Google カレンダー以外の外部サーバーへ送ることはありません。
